# Fixed Length Subnet Mask (FLSM)

## Aim

To implement subnetting using Fixed Length Subnet Mask (FLSM).

## Description

FLSM divides a network into multiple equal-sized subnets. Every subnet has the same subnet mask and the same number of hosts.

## Concepts Used

- IPv4 Addressing
- Subnet Mask
- Network Address
- Broadcast Address
- Equal-sized Subnets

## Result

Successfully implemented subnetting using FLSM.
