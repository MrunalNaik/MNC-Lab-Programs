# Variable Length Subnet Mask (VLSM)

## Aim

To implement subnetting using Variable Length Subnet Mask (VLSM).

## Description

VLSM allows different subnet sizes based on host requirements, improving IP address utilization.

## Concepts Used

- IPv4 Addressing
- VLSM
- CIDR
- Network Address
- Broadcast Address

## Result

Successfully implemented subnetting using VLSM.
